Privacy Policy — rclone-mac

Last updated: 27 September 2026

What the app is

rclone-mac is an internal tool of Verb Videók (Hungary), built on the open-source program rclone. It is used only by the studio itself, with the studio's own Google accounts.

Google user data it accesses

With the user's permission (Google Drive scope), the app lists, uploads and downloads files in the signed-in user's own Google Drive.

How the data is used

Only to back up the studio's own files and to deliver its finished videos. Files are transferred directly between the user's own computer and the user's own Google Drive.

Storage and sharing

The app has no server. It does not collect, store, sell or share Google user data with anyone. The access token is stored only on the user's own computer, and access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

rclone-mac's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Verb Videók, Hungary — through the support e-mail address shown on this app's Google consent screen.
